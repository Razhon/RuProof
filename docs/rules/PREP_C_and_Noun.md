# PREP_C_and_Noun: падеж существительного после предлога «с»

- **Правило LT:** `PREP_C_and_Noun`, `dict/grammar.xml`; правки в `build/py/fixes/prep_c_and_noun.py`
- **Образ:** `erikvl87/languagetool:6.8`, дата разбора 2026-11-10
- **док-код:** build/py/fixes/prep_c_and_noun.py

| Дефект | Тип | Причина | Статус |
|--------|-----|---------|--------|
| 1. «Брумзик ждал с полчаса», «с неделю», «прошёл с километр» отмечено: «с» + вин. п. в значении «около» | ложное срабатывание | grammar.xml | реализовано (вариант 1.1) |
| 2. «Брумзик говорил с сестру» не отмечено, «с краю» отмечено: исключение по окончанию «-у» | пропуск ошибки, ложное срабатывание | grammar.xml | реализовано (вариант 2.2) |
| 3. «Камень был с кулак» отмечено как ошибка: вин. п. неодушевлённого неотличим от сравнения | неуверенное правило как ошибка | grammar.xml | реализовано (вариант 3.1) |

## Исходное правило

Ловит существительное после «с»/«со» не в родительном и не в творительном падеже («пошёл в лес с рысь»).

```xml
<token regexp="yes">с|со<exception regexp="yes" scope="previous">величиной|размером|объёмом|объемом|длиной|высотой|шириной</exception></token>
<token postag="NN:.*:.*:.*" postag_regexp="yes"><exception regexp="yes">[а-я]*у|[!.?]</exception><exception postag="NN:.*:.*:R" postag_regexp="yes"/><exception postag="NN:.*:.*:T|UNKNOWN" postag_regexp="yes"/>…</token>
```

Винительный учтён только после слов размера в тв. п. («величиной с дом»).

## Дефект 1. «С» с винительным приблизительной меры

### Реализация

`build/py/fixes/prep_c_and_noun.py`, первая запись `PATCHES`: рядом с исключением «-у» добавлено исключение для
слов меры в вин. п.

```diff
+        r"(<exception regexp=\"yes\">\[а-я\]\*у\|\[!\.\?\]</exception>)",
+        (
+            r'\1<exception inflected="yes" regexp="yes" postag="NN:.*:V" postag_regexp="yes">'
+            r"секунда|минута|минутка|час|часок|день|денёк|сутки|неделя|месяц|год|годик|век"
+            r"|километр|метр|сантиметр|миллиметр|верста|шаг|миля|литр|килограмм|кило|грамм|тонна"
+            r"|ведро|стакан|ложка|сотня|тысяча|десяток|дюжина|пуд|фунт"
+            r"|пол-?(секунды|минуты|часа|дня|суток|недели|месяца|года|века|километра|метра|версты|литра|ведра|стакана"
+            r"|сотни|тысячи|дюжины)</exception>"
+        ),
+        1,
```

Случаи: не отмечать «Брумзик ждал с полчаса.», «Где-то с полминуты Брумзик простоял у окна.», «Брумзик ждал с
неделю.», «Брумзик прошёл с километр.»; отмечать «Брумзик пошёл в лес с рысь.», «Брумзик пришёл со стол.».
`rules.py check` (через `rpdict`) и `tools/check.ps1 selfcheck ruff pyright rules`: прошли. Корпус: +0 −0.

### Почему этот вариант

Предлог «с» с вин. п. указывает на приблизительную меру: «Работаю с месяц», «Ждать с минуту» (Большой толковый
словарь, статья «С», https://gramota.ru/poisk?query=с&mode=slovari). Правило не знало вин. п. меры, а снятие омонимии
оставляет таким словам тег `:V`. Отклонён вариант 1.2 (любое неодушевлённое в вин. п.): терял «с рысь» и «со стол»,
включая пример самого правила. Принятый риск: список мер неполон («с вершок», «с кружку»), сравнение без слова размера
(«Камень был с кулак») по-прежнему отмечается.

## Дефект 2. Исключение по окончанию «-у»: скрывало ошибки и не брало «-ю»

### Реализация

`build/py/fixes/prep_c_and_noun.py`, вторая запись `PATCHES` (после первой: её шаблон — тот же исходный фрагмент):
исключение по окончанию оставлено только неодушевлённым мужского рода и расширено на «-ю».

```diff
+        r"<exception regexp=\"yes\">\[а-я\]\*у\|\[!\.\?\]</exception>",
+        (
+            r'<exception regexp="yes">[!.?]</exception>'
+            r'<exception regexp="yes" postag="NN:Inanim:Masc:.*" postag_regexp="yes">[а-яё]*[ую]</exception>'
+        ),
+        1,
```

Случаи: не отмечать «С испугу Брумзик выронил чашку.», «Брумзик сидел с краю.», «Они встретились с глазу на глаз.»,
«Брумзик ждал с минуту.»; отмечать «Брумзик говорил с сестру.», «Брумзик гулял с собаку.», «Брумзик пришёл с брату.».
`rules.py check` и `check.ps1`: прошли. Корпус: +0 −0.

Сужение открыло сравнение по величине с вин. п. женского рода («Брумзик ростом с сестру», «с сестру ростом»): раньше
его случайно гасило исключение «-у». Сравнение «слово размера + с + вин. п.» — норма (тот же словарь: «с» с вин. п.
указывает на сходство в размере). Список слов размера в образе (`величиной|размером|объёмом|объемом|длиной|высотой|шириной`,
только перед «с») неполон, а обратного порядка нет вовсе. Модуль задаёт список `SIZE` (образ + «ростом», «весом»,
«толщиной», «глубиной», «вышиной» и формы на «-ою») и две записи `PATCHES`:

```diff
+        r'scope="previous">величиной\|размером\|объёмом\|объемом\|длиной\|высотой\|шириной<',
+        rf'scope="previous">{SIZE}<',
+        1,
...
+        r"(<exception regexp=\"yes\">\[!\.\?\]</exception>)",
+        rf'\1<exception regexp="yes" scope="next">{SIZE}</exception>',
+        1,
```

Вторая ставит исключение на существительное: слово размера сразу после него. Случаи: не отмечать «Брумзик ростом с
сестру.», «Брумзик был ростом с маму.», «Мешок весом с собаку.», «Доска толщиной с ладонь.», «Брумзик с сестру
ростом.», «Камень с собаку величиной лежал у дороги.»; отмечать «Брумзик говорил с сестру.», «Брумзик гулял с собаку
по парку.». На основном сервере проверены ещё «Яма глубиной с колодец», «Яблоко величиною с кулак», «Брумзик с маму
ростом, не выше» (молчат) и «с рысь» (отмечено). `rpdict` и `check.ps1`: прошли. Корпус не прогонялся: обе записи
только добавляют исключения, а единственное замечание правила в корпусе (несклоняемое имя) слова размера рядом не имеет.

### Почему этот вариант

После «с» допустимы родительный, в том числе второй родительный на «-у/-ю» у неодушевлённых мужского рода («с
испугу», «с краю», «с боку на бок»), творительный и вин. п. меры; вин. п. женского рода («с сестру») и дат. п. («с
брату») — ошибка (тот же словарь). Исключение снимало любое слово на «-у», потому что второй родительный размечен `:2R`
(не `:R`), а «испугу», «голоду», «перепугу» — только дательным. Отклонены: 2.1 (весь мужской род) — молчал на «с
брату»; 2.3 (только тег `:2R`) — ложные срабатывания на «с испугу», «с голоду», «с перепугу». Без 1.1 вариант
отмечал бы «с минуту», поэтому они применяются вместе. Принятый риск: дат. п. неодушевлённых мужского рода («с столу»)
молчит — по форме он совпадает со вторым родительным; «с Машу» молчит из-за глагольного омонима «машу». Сравнение
без слова размера («Камень был с кулак») — дефект 3.

## Дефект 3. Вин. п. неодушевлённого: сравнение или ошибка — не видно по форме

### Реализация

`build/py/fixes/prep_c_and_noun.py`:

- запись `PATCHES` добавляет в основное правило исключение `<exception postag="NN:Inanim:.*:V" postag_regexp="yes"/>`;
- запись `ADD` вставляет после него правило `PREP_C_and_Noun_V` с `type="style"`. У него тот же токен «с|со» и те же
  исключения (`SIZE`, `GEN2`, `MEASURE`, род. и тв. п.), но существительное только `NN:Inanim:.*:V`. Сообщение: «Возможно,
  после «с» нужен родительный или творительный падеж; если это сравнение по величине («с кулак»), ошибки нет.»;
- пример ошибки основного правила «с рысь» заменён на «с собака»: «рысь» размечена и неодушевлённой, поэтому «с рысь»
  теперь подсказка.

Случаи основного правила: не отмечать «Камень был с кулак.», «Брумзик пришёл со стол.»; отмечать «Брумзик вернулся с
работе.», «Егерь пошёл в лес с собака.», «Брумзик гулял с собака.». Случаи `PREP_C_and_Noun_V`: отмечать «Камень был
с кулак.», «Брумзик пришёл со стол.», «Брумзик пошёл в лес с рысь.»; не отмечать «со стола», «толщиной с ладонь», «с
неделю», «с краю», «с собаку». На основном сервере проверено 17 фраз: «с кулак», «с горошину», «со стол», «с рысь» —
подсказка `style`; «с сестру», «с собака», «с работе», «с брату» — ошибка; меры, второй родительный, сравнения со словом
размера — молчат. `rpdict` и `check.ps1`: прошли. Корпус не прогонялся: единственное замечание правила в корпусе
(несклоняемое имя, размеченное вин. п. неодушевлённого) по разметке переходит в подсказку.

### Почему этот вариант

Сравнение по величине «с» + вин. п. («с кулак», «с горошину») — норма (тот же словарь), и по форме оно совпадает с
опечаткой («со стол»): различает только смысл. По правилу «неуверенное — подсказка или тишина» отмечать это как ошибку
нельзя. Конструкция редкая (в корпусе 0 настоящих ошибок, 1 ложное срабатывание), поэтому подсказка почти не шумит и
сохраняет опечатки видимыми. Отклонены: молчание на всём вин. п. неодушевлённого (бывший 1.2) — теряет «со стол» и «с
рысь»; молчание только после «быть», «казаться», «стать» — оставляет «Камень с кулак лежал» ложной ошибкой. Вин. п.
одушевлённых («с сестру» без слова размера) и другие падежи остаются ошибкой: сравнения с ними без слова размера не
бывает.

## Другие правила

- **Словарь:** несклоняемое женское имя, совпадающее с нарицательным «флёр» (`флёр/NN:Inanim:Masc:Sin:V`), после
  «с» отмечается (1 раз в корпусе; после дефекта 3 — подсказкой `PREP_C_and_Noun_V`). Исправление — добавить имя как несклоняемое
  (`NN:Name:Fem` без падежа, как «Кармен») в свой слой через `rpdict`. Не исследовано.
- **Запятая при деепричастии:** «Брумзик стоял глядя на часы» — LT не отмечает пропущенную запятую перед
  деепричастным оборотом; правила для этого в LT нет. Будущий документ — `deeprichastie-zapyataya`. Не исследовано.
